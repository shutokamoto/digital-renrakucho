# デジタル連絡帳

学校現場で、手書きの連絡帳記入を減らすための印刷専用Webツールです。

## できること

- 今日の日付を自動入力
- 複数件の連絡をまとめて入力・印刷
- 連絡帳に貼りやすい実寸幅（130 / 134 / 138mm）で出力
- 本文量に合わせてカード高さを自動調整
- A4横向き・2列で紙面を効率利用
- カット用の破線付き
- 印刷時は編集UIを自動非表示
- 入力内容をlocalStorage等へ保存しない

## 印刷

A4横向きで印刷します。ブラウザの印刷設定では倍率100%を推奨します。

## Privacy

入力内容はページを開いている間だけブラウザのメモリ上に保持されます。サーバーやlocalStorageには保存しません。
